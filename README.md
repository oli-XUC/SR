# 售后服务报告 · 私有离线 PWA

本版本采用与 `H2O2 BI Cycle Calculator PWA v10 Private Offline` 相同的部署方式，并针对“iPhone 连接 Windows 移动热点”进行了设置：Windows 只在首次安装或更新时提供热点内的 HTTPS 服务；iPhone 完成缓存后，不需要电脑开机，也不需要 Cloudflare 或其他公网服务器。

## 功能与数据策略

- 手机版按 iPhone 宽度单列自适应，不需要横向拖动；输入框不会因获得焦点而自动放大。
- 手机版顶部保留“添加星期行 / 删除星期行”快捷按钮。
- 全部下拉字段在手机版均使用统一选择菜单，点击选项立即写入，同时保留手动输入。
- 报告内容、动态星期行、客户手写签字和公司手写签字自动保存在当前 iPhone 的本地存储中。
- 客户和公司签字保存后以较窄、较高的比例居中显示；签字日期完整收在表格下边框内。
- “服务工作内容”在 A4 报告和手机填写界面中均已适当增高。
- 页面资源首次缓存完成后，可在飞行模式下从主屏幕打开。
- 手机端可在完全离线状态直接生成单页 A4 PDF；完成后使用“分享/发送 PDF”调用 iPhone 文件分享，也可使用应用内正式 PDF 地址打开或下载后再发送。
- 提供“导出备份”“导入备份”“清除本机数据”。
- 报告内容和签字不会上传到服务器。
- 自动定位与附近公司地图搜索属于联网功能；离线时仍可手动填写所有字段。

## Windows 移动热点 → iPhone 首次安装

1. 解压整个压缩包。
2. Windows 打开“设置 → 网络和 Internet → 移动热点”，设置热点名称和密码，然后开启移动热点。
3. 等待约 5 秒，再双击 `START_PRIVATE_PWA.bat`，允许管理员权限。启动器会优先选择 Windows 移动热点网卡，通常地址为 `192.168.137.1`；如果没有检测到热点，会直接提示先开启热点，不会误用外部 Wi-Fi 地址。
4. iPhone 进入“设置 → Wi-Fi”，连接刚才创建的电脑热点。
5. Windows 防火墙如有提示，允许访问。脚本只开放热点本地地址的 `8180/8543` 端口，并只接受本地子网访问。
6. 启动窗口会显示两个地址：
   - 证书页面：`http://局域网IP:8180/`
   - 服务报告：`https://局域网IP:8543/`
7. 如果此 iPhone 已经安装并完全信任 BI Calculator 的 `Oliver H2O2 Local Root CA`，通常可以跳过证书安装，直接打开 HTTPS 服务报告地址。
8. 如果 Safari 提示证书不受信任：先打开证书页面并下载证书；然后进入“设置 → 通用 → VPN与设备管理”安装，再进入“设置 → 通用 → 关于本机 → 证书信任设置”开启完全信任。
9. Safari 打开 HTTPS 服务报告地址。
10. 点击“分享 → 添加到主屏幕”，开启“作为网页 App 打开”，然后添加。
11. 从主屏幕打开一次，等待顶部显示 `PRIVATE · LOCAL · OFFLINE READY · V17`。
12. 关闭 Windows 启动窗口和移动热点，iPhone 开启飞行模式，再从主屏幕打开测试。

## 日常使用

- 安装完成后，电脑不需要保持开机。
- 填写内容和签字会自动保存；重新打开 App 会恢复。
- “安装应用”按钮已从手机界面删除；安装仍通过 Safari 的“分享 → 添加到主屏幕”完成。
- 重要报告建议点击“导出备份”保存 JSON 文件。
- 删除主屏幕 Web App 或清除 Safari 网站数据，可能同时删除本地报告数据。

## 更新版本

以后更新时，先开启 Windows 移动热点，让 iPhone 连接该热点，再运行 `START_PRIVATE_PWA.bat`。Windows 移动热点通常会保持同一个本地 IP。更新前建议在旧 App 中“导出备份”，更新或重新安装后再“导入备份”。

## 可选清理

管理员运行 `OPTIONAL_CLEANUP.ps1` 可删除本应用的 Windows 防火墙规则和 HTTPS 端口绑定；为了以后继续使用 BI Calculator 和服务报告，它不会删除共用的本地根证书。
