# Service Report · GitHub Pages PWA

上传本目录全部内容到 GitHub Repository 根目录，然后：

1. GitHub Repository → Settings → Pages
2. Build and deployment → Deploy from a branch
3. Branch 选择 main，目录选择 /(root)
4. 保存并等待 GitHub Pages 发布
5. iPhone Safari 或 Android Chrome 打开 GitHub Pages 的 HTTPS 地址
6. iPhone：分享 → 添加到主屏幕
7. Android：安装应用 / 添加到主屏幕
8. 首次打开等待状态显示 GITHUB · HTTPS · OFFLINE READY · V17

这个版本不需要 Windows 本地证书，也不需要 START_PRIVATE 脚本。
表单数据和签字仍保存在手机本地浏览器/PWA 存储中。
